# BUA vs HMB(Lafarge) Financial Performance Analysis

## Project Overview.
This project presents a five-year comparative financial analysis of **BUA Cement Plc and HBM (formerly Lafarge Africa Plc)**, covering the financial years 2021–2025.

The analysis aims to support a high-net-worth client's proposed ₦25 billion investment in Nigeria's industrial goods sector, with a focus on cement production, driven by the country's urbanisation and infrastructure development needs.

Using published annual reports and financial statements, the project evaluates both companies' profitability, liquidity, solvency, operational efficiency, cash flow performance, and growth trends.

The objective is to identify each company's financial strengths and weaknesses, assess their relative investment attractiveness, and provide an evidence-based recommendation to guide the client's investment decision.
